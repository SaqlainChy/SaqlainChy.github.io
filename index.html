Fixed-Wing Surveillance UAV

Project 01 · UAV · CAD · Electronics · Integration

Fixed-Wing Surveillance UAV

A multidisciplinary final-year design project combining airframe design, fabrication, avionics, power, embedded computing, camera hardware, and flight-control integration.

UAV MAIN IMAGEassets/images/uav/

Overview

From airframe to integrated flight system

The project brought mechanical design, lightweight fabrication, propulsion, control surfaces, avionics, embedded computing, and a camera payload into one aircraft platform.

My Contribution

Design, assembly, and integration

  • Designed the UAV airframe and fuselage in Fusion 360.
  • Fabricated and assembled the lightweight structure using LW-PLA.
  • Integrated propulsion, servos, flight controller, Raspberry Pi, camera, and onboard electronics.
  • Configured and calibrated the RC system, ESC, servos, and control surfaces.
  • Supported camera gimbal integration, hardware debugging, calibration, and system testing.

Technical Implementation

System focus

  • Mechanical CAD and lightweight fabrication
  • Electrical and power-system integration
  • Flight-controller setup and calibration
  • Raspberry Pi / flight-system integration
  • Payload integration and debugging
